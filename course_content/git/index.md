# Git & Version Control

Why version control matters, how Git came to be, installing and configuring Git, core terminology and hands-on exercises.

## How each session works

1. **The big idea**: the topic in plain words, with an everyday example.
2. **A picture**: a diagram of the idea.
3. **Real commands**: every script was run with Git 2.34 and the output you see is what it printed.
4. **Common mistakes**: what trips beginners up.
5. **Hands-on exercises**: try first, then open the solution.
6. **Practice**: a quiz for the session.

:::{tip}
The scripts in `code/` run in a throwaway folder with their own settings, so you can run them without touching
your real Git configuration. Want the whole story, with branches, remotes and GitHub? Continue with
*Git: Basics to Intermediate*.
:::
