# 40 Days of Agentic AI

Welcome! In this course you'll learn to build **AI agents**: programs that use an AI model to
**think**, **use tools**, **look things up** and **remember**. You don't need any AI background.
We start from Python basics and add one small idea at a time.

:::{note}
**What is an AI agent, in one line?** It's like a smart assistant that doesn't just chat. It can
also *do* things: check the weather, read your files, search a database, then give you an answer.
:::

## How each session page works

Every session page follows the same pattern, so you always know where to look:

1. **The big idea**: the concept in two sentences, with an everyday example.
2. **Step-by-step explanation**: simple words, pictures (diagrams) and small code examples that
   show the *input* and the *output*.
3. **Common mistakes**: what usually goes wrong, so you can avoid it.
4. **Try it yourself**: short exercises, with answers you can reveal.
5. **Full source**: the complete code from the live class, ready to copy or download.

AI answers shown in the examples are what a typical run looks like. When you run the code, the
wording may differ a little; the idea stays the same.
