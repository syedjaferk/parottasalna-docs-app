# Python Fundamentals

Learn Python from your very first `print()` to building a complete game. Every session explains
one idea with everyday examples (delivery trucks, photo albums, the annachi kadai down the street),
shows real code with its real output, and ends with **hands-on tasks** with solutions you can
reveal when you're stuck.

:::{note}
**Free for everyone.** No sign-up needed to read. Sign in to save your quiz scores, flashcard
progress and notes.
:::

## How to use this course

1. **Install Python 3** from [python.org](https://www.python.org/downloads/) (tick *Add Python to
   PATH* on Windows), or use [Google Colab](https://colab.research.google.com/) in the browser with
   nothing to install.
2. **Type the examples yourself.** Don't copy-paste. Typing is how your fingers learn Python.
3. **Do the tasks** at the end of each session before opening a solution.
4. **Take the quiz and flashcards** linked at the bottom of each session.

Each session is based on a post from the [Parottasalna blog](https://learn.parottasalna.com/blog/),
linked at the top of the page.
