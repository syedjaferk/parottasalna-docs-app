How to use the playground

  1. Start with the URL shortener. It teaches the whole routine: requirements, numbers, API, design, deep dive, failures, trade-offs.
  2. Learn a building block, then design with it. Read the chapter on caching, load balancing or queues, then open the problem that uses it.
  3. Decide before you read. Every step asks for your answer first. Use the hint only after you tried.
  4. Finish with the scorecard. It shows which interview phase is weakest, and gives you a few lines to say out loud.

New to system design?
